# MyCard.io for Android

**Scan. Share. Save.** Keep your receipts, business cards and loyalty cards in one app.

## Download

- **Download page:** https://mdferuzhossain.github.io/mycard-io-download/
- **Direct download** (always the newest version):
  https://github.com/mdferuzhossain/mycard-io-download/releases/latest/download/MyCard.io.apk

Works on Android 7 or newer. Free.

## How to install

1. Open the download page on your Android phone and tap **Download for Android**.
2. Open the downloaded file.
3. If asked, tap **Settings**, turn on **Allow from this source**, and go back.
4. Tap **Install**. If Play Protect warns you, tap **More details**, then **Install anyway**.

To update, download and install again. Your data stays.

## What is in this repository

This repository only holds the public download page (`index.html`) and the app files (under **Releases**).
The app's source code is kept in a separate private repository.

## Privacy

Photos are only used to read the details and are never saved. Only the text is kept. Full card numbers are never stored.
